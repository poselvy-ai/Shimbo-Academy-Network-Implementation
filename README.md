# Shimbo Academy Network Implantation 
> Technical Project Coordination Portfolio
## Project Overview 
The repository document is an end-to-end summary of a technical infrastructure implementation project for the ***Shimbo Academy***, a fictional school based in Zambia, Africa, preparing to introduce technology‑based education and classroom computing in a semi‑remote location of Zambia.

I created this project to demonstrate how I would coordinate the technical implementation and design the network, from the initial customer request through the project planning, execution, issue resolution, testing, customer acceptance, operational handoff, and close out. 

The repository focus on project-coordination responsibilities surrounding technical work, including:

- Translating customers needs into defined project requirements.
- Establishing project scope, objectives, assumptions, and acceptance criteria.
- Organizing activities, milestones, technical personnel, and vendors.
- Tracking project risks, issues, decisions, and action items.
- Managing changes to requirements, schedules, and scope.
- Communication of project status.
- Coordinating testing, customer acceptance, and operational handoff.
- Documenting outcomes and lessons learned.
